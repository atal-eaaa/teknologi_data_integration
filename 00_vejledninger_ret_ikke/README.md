# Vejledninger – ret ikke i disse filer

Denne mappe indeholder vejledninger og opslagsmateriale fra underviserne (fx formelsamlingen).

**Du må gerne læse, printe og kopiere filerne, men ret ikke i dem her.** Underviserne opdaterer dem løbende, og hvis du har rettet i en fil, kan `git pull` fejle.

Vil du have dine egne noter i en af filerne, så lav en kopi i en anden mappe og ret i kopien.

| Fil | Indhold |
|---|---|
| `git_guide.md` | Sådan får du dit eget repo, så din kode kan bruges på flere computere |
| `git_fejl.md` / `.html` / `.pdf` | Typiske git-fejl og hvordan de løses (PDF'en er klar til print) |
| `formelsamling_python.md` / `.html` / `.pdf` | Formelsamling til Python |
